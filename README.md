# SequenceBox 數字拼圖

把數字方塊拼到棋盤上，讓每一格和上下左右的鄰格**剛好差 1**。

線上試玩：<https://cnshow2025.github.io/sequencebox/>

## 玩法

- 棋盤上有粗框、小圓點的是**種子**，固定不能動。
- 把下方方塊區的方塊拖到棋盤上，填滿所有格子就過關。
- 點一下方塊：順時針旋轉 90°（在棋盤上時以點到的那一格為中心旋轉）。
- 把棋盤上的方塊拖出棋盤：放回方塊區。
- 紅框：那兩格沒有剛好差 1。
- 💡 提示：把一個方塊放到正確位置；↺ 重來：重新開始本關。

小技巧：相鄰兩格一定一奇一偶，就像西洋棋盤的黑白格；和種子相隔 d 步的格子，數字最多差 d。

## 難度

| 難度 | 棋盤 | 種子 | 方塊 |
|---|---|---|---|
| 簡單 | 3×3 | 2 個 | 1～3 格 |
| 中等 | 4×4 | 1 個 | 1～3 格，大塊較多 |
| 困難 | 5×5 | 1 個 | 1～3 格，大塊最多 |

數字範圍 1～9。每一關用固定的亂數種子產生，所以同一關每次都是同一題；進度存在瀏覽器的 localStorage。

## 關卡怎麼產生

1. 從左上角逐格填出完整答案：每格只看左邊和上面的鄰格——兩者相同就隨機填 ±1，差 2 就填中間。因為奇偶交替，一定填得下去。
2. 選出種子格，把其餘格子切成 1～3 格的方塊（單格、兩格、三格直條、L 形）。
3. 每個方塊隨機旋轉後放進方塊區。
4. 判定只看規則（填滿且相鄰都差 1），不和標準答案比對，找到其他合法擺法也算過關。

## 執行

純 HTML + CSS + JavaScript，不需要安裝或編譯，直接用瀏覽器打開 `index.html` 即可。推送到 `main` 後，`.github/workflows/pages.yml` 會自動部署到 GitHub Pages。

```
index.html        頁面
css/style.css     樣式（手機優先，支援深色模式）
js/generator.js   產生答案 → 切成方塊 → 隨機旋轉
js/game.js        拖放、旋轉、判定、衝突標紅、提示
js/main.js        難度切換、進度存檔、畫面尺寸
```
